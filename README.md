# Market-Manager

Приложение для управления магазином с ИИ-агентом. Система учитывает товары и продажи, делает отчёты, прогнозирует спрос и с помощью камер помогает выявлять подозрительные действия (возможные кражи) до выхода из магазина или на кассе.

## Идея

1. Кассир или сканер считывает штрихкод товара, система ведёт учёт продаж и остатков.
2. ИИ-агент читает данные из базы и пишет отчёты простым языком.
3. Модель прогнозирует спрос на товары.
4. Камеры анализируют поведение в зале и на кассе и отмечают подозрительные моменты для сотрудника охраны. Решение всегда принимает человек, система только подсказывает.

## Модули и план разработки

Разрабатываем по порядку. Следующий модуль начинаем, когда предыдущий работает.

### Модуль 1. База данных и учёт (фундамент)

**Что делает:** хранит товары, остатки, продажи и чеки. Находит товар по штрихкоду.

**Минимум для готовности:**
- [ ] таблица `products` (штрихкод, название, цена, остаток)
- [ ] таблицы `sales` и `sale_items` (продажи и позиции чека)
- [ ] API: добавить товар, найти по штрихкоду, оформить продажу
- [ ] остаток уменьшается после продажи

**Что учить:**
- Python (основы: переменные, функции, списки, словари, классы)
- SQL и SQLite (таблицы, SELECT, INSERT, JOIN)
- FastAPI (создание API)
- Git и GitHub (commit, push)

### Модуль 2. Штрихкоды

**Что делает:** считывает штрихкод товара и передаёт его в учёт.

**Минимум для готовности:**
- [ ] поле ввода штрихкода (подходит USB-сканер, он работает как клавиатура, или ручной ввод)
- [ ] чтение штрихкода с камеры (позже)

**Что учить:**
- OpenCV (работа с изображением и камерой)
- `pyzbar` или `zxing-cpp` (распознавание штрихкодов)

### Модуль 3. Отчёты и ИИ-агент

**Что делает:** агент читает данные из базы и отвечает на вопросы вроде «что продавалось хуже всего на этой неделе?». Формирует ежедневный и еженедельный отчёты.

**Минимум для готовности:**
- [ ] отчёты: выручка, топ товаров, что заканчивается
- [ ] агент получает данные из базы и пишет текст отчёта
- [ ] панель с отчётами

**Что учить:**
- pandas (анализ таблиц)
- работа с API языковой модели (запросы, промпты, tool use / function calling)
- Streamlit (быстрая панель на Python)

### Модуль 4. Прогноз спроса

**Что делает:** по истории продаж предсказывает, сколько товара понадобится в ближайшие дни и недели.

**Минимум для готовности:**
- [ ] простой прогноз (скользящее среднее)
- [ ] модель получше (регрессия, Prophet)
- [ ] подсказки «пора заказывать товар»

**Что учить:**
- pandas и numpy
- scikit-learn (основы машинного обучения)
- Prophet или statsmodels (прогноз временных рядов)
- основы статистики: среднее, тренд, сезонность

### Модуль 5. Камеры и выявление краж

**Что делает:** анализирует видео из зала и с кассы, отслеживает людей и действия, помечает подозрительные моменты.

**Минимум для готовности:**
- [ ] распознавание людей на видео
- [ ] отслеживание человека между кадрами
- [ ] простая тревога (например, человек с товаром идёт мимо кассы)
- [ ] сохранение коротких фрагментов видео для проверки сотрудником

**Что учить:**
- OpenCV
- YOLO (Ultralytics) для обнаружения людей и объектов
- трекинг объектов (ByteTrack, DeepSORT)
- основы нейросетей и компьютерного зрения

**Важно:** система не обвиняет человека, а только отмечает момент для проверки охранником. В реальном магазине нужны таблички о видеонаблюдении и аккуратное хранение записей (закон о персональных данных).
